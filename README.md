 E-commerce Core

Ядро интернет-магазина с базовыми сущностями: **товары** и **категории**.

## Основные возможности:
- **Product**:
  - Атрибуты: название, описание, цена, количество.
  - Приватный атрибут цены.
  - Геттеры и сеттеры для работы с ценой (проверка на положительное значение).
  - Класс-метод `new_product` для создания нового продукта из словаря.
- **Category**:
  - Приватный список товаров.
  - Метод `add_product` для добавления товаров.
  - Геттер для вывода списка товаров в формате:  
    `Название продукта, X руб. Остаток: X шт.`.
  - Автоматический подсчет количества категорий и товаров.

## Тестирование:
- Покрытие тестами: >75%.
- Запуск тестов: `pytest`.

## Использование:
1. Создайте объекты `Product` и `Category`.
2. Добавьте товары в категории.
3. Используйте геттеры для просмотра данных.
