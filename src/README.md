# E-commerce Project

Этот проект представляет собой ядро интернет-магазина, реализованное с использованием объектно-ориентированного программирования (ООП). В проекте определены классы для товаров (`Product`) и категорий (`Category`), которые могут быть использованы для создания функционального интернет-магазина.

## Описание проекта
Проект реализует базовые сущности для интернет-магазина:
- **Товары** (`Product`): представляют товары с атрибутами `name`, `description`, `price` и `quantity`.
- **Категории** (`Category`): представляют категории товаров с атрибутами `name`, `description` и списком товаров. Также включают счетчики `category_count` (количество категорий) и `product_count` (общее количество товаров).
